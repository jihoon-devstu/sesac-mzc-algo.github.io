## 접근

1. "방법의 수"를 구하고 답을 `10^9+7`로 나누라고 한다. n이 커서 전부 만들어볼 수 없으니, 작은 판의 답으로 큰 판의 답을 만드는 DP로 접근한다.
2. `f[i]` = 2×i 판을 꽉 채우는 방법의 수.
3. 판의 오른쪽 끝이 어떤 조각으로 끝나는지로 경우를 나눈다.
   - 세로 도미노로 끝남 → 떼면 2×(i-1) 판이 남음 → `f[i-1]`
   - 가로 도미노 2개로 끝남 → 떼면 2×(i-2) 판이 남음 → `f[i-2]`
   - 트로미노로 끝남 → 떼면 한 칸 튀어나온 판이 남음 → 위/아래 두 방향이라 `2 * p[i-2]`
4. 튀어나온 판은 `f`로 셀 수 없어서 상태를 하나 더 둔다. `p[i]` = i칸은 꽉 차 있고 다음 칸의 위(또는 아래) 한 칸만 채워진 판의 방법의 수.
   - 트로미노로 끝남 → `f[i-1]`
   - 가로 도미노로 끝남 → 반대쪽으로 튀어나온 판 → `p[i-1]`
5. 점화식
   - `f[i] = f[i-1] + f[i-2] + 2 * p[i-2]`
   - `p[i] = p[i-1] + f[i-1]`
6. 빈 판을 채우는 방법은 "아무것도 안 놓기" 1가지라서 `f[0] = 1`로 둔다.

## 풀이

```java
class Solution {
    public int numTilings(int n) {
        final int MOD = 1_000_000_007;
        if (n <= 2) return n;

        long[] f = new long[n + 1];
        long[] p = new long[n + 1];

        f[0] = 1; f[1] = 1; f[2] = 2;
        p[0] = 0; p[1] = 1; p[2] = 2;

        for (int i = 3; i <= n; i++) {
            f[i] = (f[i-1] + f[i-2] + 2 * p[i-2]) % MOD;
            p[i] = (p[i-1] + f[i-1]) % MOD;
        }
        return (int) f[n];
    }
}
```

시간 O(n), 공간 O(n)
