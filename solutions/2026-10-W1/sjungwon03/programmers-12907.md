## 문제 설명

- N을 만들 수 있는 경우의 수 구하기

## 접근

- DP

## 풀이

```js

function solution(n, money) {
    const MOD = 1_000_000_007;

    const dp = new Array(n + 1).fill(0);

    // 동전을 하나도 사용하지 않고 0원을 만드는 방법은 1가지
    dp[0] = 1;

    // 사용할 수 있는 동전 종류를 하나씩 추가
    for (const coin of money) {
        // 오름차순으로 순회하므로 같은 동전을 여러 번 사용할 수 있음
        for (let amount = coin; amount <= n; amount++) {
            dp[amount] =
                (dp[amount] + dp[amount - coin]) % MOD;
        }
    }

    return dp[n];
}
```

시간복잡도 O(money * n)

## AI 풀이
이 문제는 **사용할 수 있는 동전 종류를 하나씩 늘려 가면서, 각 금액을 만드는 경우의 수를 누적하는 DP**로 접근하면 돼요.

## 1. 문제 접근 방식

`money = [1, 2, 5]`라면 다음 순서로 계산해요.

```text
1원만 사용해서 각 금액을 만드는 방법 계산
                  ↓
1원, 2원을 사용해서 각 금액을 만드는 방법 계산
                  ↓
1원, 2원, 5원을 사용해서 각 금액을 만드는 방법 계산
```

이때 배열의 의미를 다음처럼 정해요.

> **`dp[amount]` = 지금까지 처리한 동전 종류를 사용해서 `amount`원을 만드는 방법의 수**

새로운 동전 `coin`을 사용할 수 있게 되면, `amount`원을 만드는 방법을 두 가지로 나눌 수 있어요.

```text
① 현재 동전을 사용하지 않는 방법
   → 이전 동전들만으로 계산해 둔 기존 dp[amount]

② 현재 동전을 하나 이상 사용하는 방법
   → amount - coin원을 만드는 각 조합에 coin 동전 하나를 추가
   → dp[amount - coin]
```

두 경우는 **현재 동전의 사용 여부로 구분되므로 서로 겹치지 않아요.** 따라서 더하면 됩니다.

```javascript
dp[amount] += dp[amount - coin];
```

단, 오른쪽의 `dp[amount - coin]`에는 **현재 동전을 사용하는 방법까지 포함되어 있어야 해요.** 같은 동전을 여러 번 사용할 수 있기 때문이에요.

## 2. 최종 코드

```javascript
function solution(n, money) {
    const MOD = 1_000_000_007;

    // dp[amount]: 현재까지 처리한 동전으로 amount원을 만드는 방법의 수
    const dp = new Array(n + 1).fill(0);

    // 아무 동전도 사용하지 않고 0원을 만드는 방법은 1가지
    dp[0] = 1;

    // 사용할 동전 종류를 하나씩 추가
    for (const coin of money) {
        // 작은 금액부터 계산하여 같은 동전을 여러 번 사용할 수 있게 함
        for (let amount = coin; amount <= n; amount++) {
            dp[amount] =
                (dp[amount] + dp[amount - coin]) % MOD;
        }
    }

    return dp[n];
}
```

## 3. 코드 설명

### ① 배열 초기화

```javascript
const dp = new Array(n + 1).fill(0);
dp[0] = 1;
```

0원부터 `n`원까지 저장해야 하므로 배열 크기는 `n + 1`이에요.

아직 어떤 동전도 처리하지 않았으므로 양수 금액을 만드는 방법은 모두 0가지예요.

```text
n = 5일 때

금액:  0  1  2  3  4  5
dp:   [1, 0, 0, 0, 0, 0]
```

**0원은 아무 동전도 선택하지 않으면 만들 수 있으므로 1가지**로 설정해요.

이 값은 동전 하나만 사용하는 방법을 계산하는 출발점이기도 해요.

```text
0원을 만드는 조합: []

여기에 2원 동전을 추가:
[] + [2] → [2]
```

코드에서는 다음 계산에 해당해요.

```javascript
dp[2] += dp[0]; // 2원 동전 하나로 만드는 방법 1가지 추가
```

### ② 동전 종류를 하나씩 처리

```javascript
for (const coin of money) {
```

`money = [1, 2, 5]`라면 1원, 2원, 5원 순서로 처리해요.

**동전 종류를 바깥 반복문에 두는 이유는 순서만 다른 조합을 중복해서 세지 않기 위해서예요.**

예를 들어 2원을 처리할 때 다음 조합이 만들어져요.

```text
기존 [1]에 2원 추가 → [1, 2]
```

이후 다시 1원 처리 단계로 돌아가지는 않으므로 다음 조합을 별도로 만들지 않아요.

```text
[2]에 1원 추가 → [2, 1]
```

이렇게 **동전을 추가하는 순서를 고정하면, 같은 동전 구성은 한 번만 계산**됩니다.

### ③ 현재 동전으로 만들 수 있는 금액부터 계산

```javascript
for (let amount = coin; amount <= n; amount++) {
```

`amount`가 `coin`부터 시작하는 이유는 **현재 동전보다 작은 금액에는 그 동전을 사용할 수 없기 때문**이에요.

```text
coin = 2라면 → 2원부터 계산
coin = 5라면 → 5원부터 계산
```

그리고 금액을 **오름차순으로 계산하는 이유는 같은 동전을 여러 번 사용하기 위해서**예요.

예를 들어 2원 동전을 처리할 때:

```text
amount = 2
→ dp[2]에 [2]라는 방법이 추가됨

amount = 4
→ 방금 갱신한 dp[2]를 이용
→ [2]에 2원 하나를 추가한 [2, 2]도 계산됨
```

즉, **현재 동전을 사용해서 만든 결과를 뒤의 계산에서 다시 활용**할 수 있어요.

### ④ 기존 방법에 새로운 방법을 더하기

```javascript
dp[amount] =
    (dp[amount] + dp[amount - coin]) % MOD;
```

`coin = 2`, `amount = 5`인 순간을 볼게요.

```javascript
dp[5] += dp[3];
```

이때 두 값의 상태가 달라요.

| 값 | 의미 | 해당 조합 |
|---|---|---|
| 갱신 전 `dp[5] = 1` | 아직 2원 동전을 사용하지 않고 5원을 만드는 방법 | `[1, 1, 1, 1, 1]` |
| 이미 갱신한 `dp[3] = 2` | 1원과 2원을 사용해서 3원을 만드는 방법 | `[1, 1, 1]`, `[1, 2]` |

`dp[3]`의 각 조합에 2원 동전 하나를 붙이면:

```text
[1, 1, 1] + [2] → [1, 1, 1, 2]
[1, 2]    + [2] → [1, 2, 2]
```

따라서 기존 1가지에 새로운 2가지가 추가돼요.

```javascript
dp[5] = 1 + 2; // 3가지
```

`% MOD`는 문제 조건에 맞게 **계산할 때마다 1,000,000,007로 나눈 나머지를 저장**하는 부분이에요.

### ⑤ 모든 동전을 처리한 뒤 정답 반환

전체 배열은 다음처럼 변해요.

| 처리한 동전 | `dp[0]` | `dp[1]` | `dp[2]` | `dp[3]` | `dp[4]` | `dp[5]` |
|---|---:|---:|---:|---:|---:|---:|
| 없음 | 1 | 0 | 0 | 0 | 0 | 0 |
| 1원 | 1 | 1 | 1 | 1 | 1 | 1 |
| 1원, 2원 | 1 | 1 | 2 | 2 | 3 | 3 |
| 1원, 2원, 5원 | 1 | 1 | 2 | 2 | 3 | **4** |

마지막으로 5원 동전을 처리하면서 다음 방법이 추가돼요.

```javascript
dp[5] += dp[0]; // 기존 3가지 + [5]라는 1가지
```

모든 동전을 처리했으므로 `dp[n]`이 최종 정답이에요.

```javascript
return dp[n];
```

동전 종류 수를 `m`이라고 하면 **시간 복잡도는 `O(m × n)`, 공간 복잡도는 `O(n)`**이에요.

핵심 점화식은 이렇게 읽으면 됩니다.

> **`amount`원을 만드는 기존 방법에, `amount - coin`원을 만드는 각 방법마다 현재 동전 하나를 붙인 방법을 더한다.**
